# Semester GPA Calculator

A beginner Java console application that calculates a semester
marks average and a credit-weighted GPA.

## Features

- Accepts 1 to 10 subjects
- Records subject names, marks and credits
- Validates user input
- Assigns grades and grade points
- Displays a subject results table
- Calculates semester average and GPA

## Technologies

- Java
- Java Scanner
- Arrays and methods

## How to Run

1. Install a Java Development Kit (JDK 8 or newer).
2. Open the project in IntelliJ IDEA.
3. Configure the project JDK.
4. Run the main method in Main.java.
5. Enter the subject details in the console.

## Example

| Subject | Marks | Credits |
|---|---:|---:|
| Java | 80 | 3 |
| Database | 70 | 4 |
| Mathematics | 60 | 2 |

Expected marks average: 70.00
Expected GPA: 3.64

## Grading Notice

This project uses a practice grading scale.
It does not represent the official SLIIT grading policy.

## Current Limitation

Results are held in memory and are not saved after the program exits.
